End-to-End Data Analytics: US Greenhouse Gas Emissions using Databricks

📋 Project Summary:

This project showcases a complete data analytics lifecycle using the Databricks . By analyzing United States greenhouse gas emissions data, the project delivers actionable insights through interactive dashboards, reflecting real-world skills in data cleaning, SQL querying, and visual storytelling.

💼 Business Context :
The project simulates an environmental reporting scenario. The primary objective is to support sustainability initiatives by:

Identifying emission "hotspots" across states and counties.

Understanding the relationship between population density and carbon footprints.

Providing decision-makers with a granular view of emissions at a per-person level.
