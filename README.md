# Databricks
Building an End to End Data Analytics Project in Databricks Free Edition
##Project Summary

This project showcases a complete data analytics lifecycle using Databricks 
It focuses on analyzing United States greenhouse gas emissions data and delivering insights through interactive dashboards
The project reflects real world analytical thinking data cleaning SQL querying and visualization skills



#Business Context

The project simulates a scenario where an analyst is supporting environmental reporting requirements
The goal is to identify emission hotspots across states and counties and understand emissions at a per person level

#Data Source

Public EPA greenhouse gas emissions dataset

County level data including emissions population latitude and longitude

Raw dataset imported into Databricks from GitHub

Tools and Technologies

Databricks Free Edition

Databricks SQL

SQL for data transformation and analysis

Databricks Dashboards

Built in AI assistant for SQL generation and debugging

#Project Objectives

Analyze greenhouse gas emissions across the United States

Identify high emission states and counties

Calculate emissions per person using population data

Visualize geographic emission patterns

Build an interactive dashboard for stakeholder consumption

#Data Preparation

Created a new Databricks catalog and table

Loaded raw data without pre transformation

Identified numeric fields stored as text

Removed thousand separators from emissions values

Converted emissions and population columns to numeric data types

#Key SQL Analysis

Total emissions by state

Top ten emitting states

Top ten emitting counties

Emissions per person by county

Population versus emissions comparison

#Dashboard Visualizations

Geographic point map of emissions using latitude and longitude

Scatter plot showing emissions per person versus population

Bar chart ranking counties by total emissions

Pie chart displaying emissions share of top states

#Key Insights

A small number of states account for a large share of total emissions

High population regions generally show lower emissions per person

Some low population counties exhibit very high emissions per person

Emissions are concentrated in central and eastern regions of the United States

#Final Output

The final Databricks dashboard includes

United States emissions map

Emissions versus population analysis

State level emissions contribution

County level emissions ranking

The dashboard is designed for non technical users and decision makers
